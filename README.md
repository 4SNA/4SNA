## ⚙️ One-Time Setup Instructions

<details>
<summary><b>🐍 Snake animation setup (click to expand)</b></summary>

1. In your profile repo (`4SNA/4SNA`), create the file `.github/workflows/snake.yml` with this content:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [main]

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: 4SNA
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

2. Go to **Settings → Actions → General** and set Workflow permissions to **Read and write**.
3. Run the workflow manually once from the **Actions** tab to generate the first snake.

</details>

<details>
<summary><b>⏱️ WakaTime stats setup (click to expand)</b></summary>

1. Sign up at [wakatime.com](https://wakatime.com) and install the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=WakaTime.vscode-wakatime).
2. Copy your **Secret API Key** from [wakatime.com/settings](https://wakatime.com/settings/api-key).
3. In your GitHub profile repo, go to **Settings → Secrets → Actions** and add:
   - `WAKATIME_API_KEY` — your WakaTime key
   - `GH_TOKEN` — a GitHub Personal Access Token with `repo` scope
4. Create `.github/workflows/waka-readme.yml`:

```yaml
name: Waka Readme

on:
  schedule:
    - cron: '30 18 * * *'
  workflow_dispatch:

jobs:
  update-readme:
    runs-on: ubuntu-latest
    steps:
      - uses: anmol098/waka-readme-stats@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
          GH_TOKEN: ${{ secrets.GH_TOKEN }}
          SHOW_OS: "False"
          SHOW_PROJECTS: "False"
          SHOW_TIMEZONE: "False"
          SHOW_COMMIT: "True"
          SHOW_DAYS_OF_WEEK: "True"
```

5. Run it manually once from the **Actions** tab. After that it auto-updates daily.

</details>

<details>
<summary><b>🎵 Spotify now playing setup (click to expand)</b></summary>

1. Fork [novatorem/novatorem](https://github.com/novatorem/novatorem).
2. Go to [Spotify Developer Dashboard](https://developer.spotify.com/dashboard/) → create an app → copy Client ID & Secret.
3. Deploy the fork to [Vercel](https://vercel.com) and add your Spotify credentials as environment variables.
4. Replace `https://novatorem.vercel.app/api/spotify` in this README with your own deployed Vercel URL.

</details>
